# Multi-Channel Revenue & Attribution Engine (Open-Core)

> Lightweight, privacy-compliant first-party attribution tracking library for modern web applications.

[![License: MIT](https://img.shields.io/badge/License-MIT-gold.svg)](LICENSE)
[![TypeScript](https://img.shields.io/badge/TypeScript-5.0-blue.svg)](https://www.typescriptlang.org/)

## 🛠 Features
- Parse UTM parameters (`utm_source`, `utm_medium`, `utm_campaign`) and click IDs (`gclid`, `fbclid`).
- Store first-touch and last-touch attribution payloads in client storage.
- Zero external dependencies. Fast payload (<1.5KB).
